# Task Overflow

A modern, intuitive task management application designed to help users organize their daily activities, manage priorities, and keep track of their productivity.

## Overview

Task Overflow is a personal productivity application built with Next.js and TypeScript. Its goal is to provide a clean and straightforward experience for creating, organizing, and tracking tasks.

## Tech Stack

- **Next.js** – React framework for the application.
- **TypeScript** – Static typing and improved code reliability.
- **React** – Component-based user interface.
- **Tailwind CSS** – Utility-first styling.
- **ESLint** – Code quality and consistency.

## Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js 20.9 or later
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/itsdingos/task-overflow.git
   ```

2. Navigate to the project directory:

   ```bash
   cd task-overflow
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open [http://localhost:3000](http://localhost:3000) in your browser.
